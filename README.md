# TallerBD-2026-Medina-Luis
Proyecto final de Taller de base de datos de Luis Carlo Medina Saucedo

Proposito:
El proposito del proyecto es realizar una aplicacion en la que se pueda hacer seguimiento de los prestamos de material/equipo para actividades academicas, administrativas, eventos, etc.

Modelo de datos:
Utiliza el motor InnoDB para garantizar integridad referencial y soporte transaccional.
